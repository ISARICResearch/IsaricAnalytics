.. _visualisation:

=============
Visualisation
=============

A variety of figures / plots can be generated using figure functions in the :py:mod:`~isaricanalytics.visualisation` library, and this can be  explored in more detail in the plot gallery below. Note that all functions return a :py:class:`Plotly Go Figure <plotly.graph_objs._figure.Figure>` object.

.. note::

   The plot gallery is under development, and not all figure functions in :py:mod:`~isaricanalytics.visualisation` have a corresponding panel in the plot gallery. More panels will be added over time.
